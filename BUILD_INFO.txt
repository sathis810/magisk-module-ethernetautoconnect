====================================
WHY UI-ONLY MODE?
====================================

Advantages:
  ✅ Works on ANY Android device with UI
  ✅ No special system permissions required
  ✅ Works on locked-down OEM ROMs
  ✅ More consistent across Android versions
  ✅ User can see what's happening
  ✅ No dependency on CLI API changes

Considerations:
  ⚠️ Screen must be unlocked on first boot
  ⚠️ Slightly slower (2-5 seconds vs instant)
  ⚠️ May need calibration on custom ROMs (rare)

====================================
AUTOMATION FLOW
====================================

1. Boot → Service starts
2. Monitor → Check eth0 every 5 seconds
3. Detect → Cable connected + No IP
4. Trigger → Immediately open Settings (no CLI attempts)
5. Navigate → Find Tethering settings
6. Detect → Use UIAutomator to find toggle
7. Tap → Click Ethernet toggle
8. Verify → Check IP assignment
9. Log → Success or failure
10. Retry → If failed, wait 5 minutes and repeat

====================================
KNOWN LIMITATIONS
====================================

- Requires 'uiautomator' command (available on most devices)
- Screen must be unlocked when automation triggers
- DHCP server must be available on network
- Some OEM skins may have different Settings layouts
- First boot may require manual unlock
