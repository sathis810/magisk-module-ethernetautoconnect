FEATURES IN THIS BUILD
====================================

   - Detects cable connection via carrier status
   - Checks IP assignment status

✅ Multi-Method Enabling:
   - Command-line methods (3 attempts with 30s cooldown)
     • cmd connectivity tether ethernet on
     • ndc tether interface add eth0
     • ip link set eth0 up

   - Tier 2: Dynamic screen positioning (resolution-aware)
   - Tier 3: DPAD navigation (universal fallback)

   - Verifies IP assignment after UI automation
   - Auto-retries after 5 minutes if unsuccessful
   - Comprehensive logging

====================================
INSTALLATION
====================================

1. Transfer to device:
   adb push force-ethernet-always-on-v1.10.zip /sdcard/

2. Install via Magisk Manager:
   - Open Magisk Manager
   - Modules → Install from storage
   - Select force-ethernet-always-on-v1.10.zip
   - Reboot
